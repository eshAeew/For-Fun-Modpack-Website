# 🎮 For Fun i guess — Official Showcase Website

> *Interactive creature bestiary, biome explorer, structure coordinates, and mod catalog for the **For Fun i guess** Minecraft Fabric 1.21.4 modpack.*

---

## 🌟 Overview

Welcome to the official repository for the **For Fun i guess** modpack website. This interactive web application allows players to:
- 👾 **Wildlife & Mob Bestiary**: Browse 75+ reworked creatures (Creepers, Endermen, Spiders, Friends & Foes, Apple Cows, and Critters) complete with in-game renders, HP stats, danger ratings, and click-to-copy `/summon` commands.
- 🌍 **World Generation & Structures**: Explore custom biomes and structures across Terralith, Biomes O' Plenty, and Amplified Nether with in-game `/locate` commands.
- 📚 **Curated Mod Directory**: View all 119 curated mods, official author attributions, and direct links to wikis and source pages.
- ☕ **Creator Support**: Direct community links for Ko-fi and Patreon.
